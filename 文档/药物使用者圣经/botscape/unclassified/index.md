

未分类 [\#](#未分类)

[◀返回](../index.md)

> **教科书定义：** 有一些植物材料产生的效应，没法舒舒服服地归进前面那些分类里呢。比如说，有的会引发多种效应的组合，带来非常独特的体验。还有的会在体验展开的过程中产生不同的效果哦。
>
> 以下这些植物材料已经过采样和研究，并收录在本节里：

> * [精油](./essential_oils.md)
>
> * [卡瓦](./kava_kava.md)
>
> * [卡痛](./kratom.md)
>
> * [疯蜜](./mad_honey.md)
>
> * [马帕乔](./mapacho.md)
>
> * [鸦片](./opium.md)
>
> * [拉佩](./rapey.md)
>
> * [沙凯纳](./sakae_naa.md)
>
> * [烟草](./tobacco.md)

像大麻这种精神活性植物，效应那么多样，你怎么可能把它塞进单一分类里呢？Erowid 就这么描述它：“致醉剂；兴奋剂；迷幻剂；抑制剂”。

那马帕乔呢？先是一记重击，最后又变得清晰？

还有卡痛的情绪提升、半欣快感，以及最终的镇静？

这些都是例子哦，它们的特性就是没法舒舒服服地归进本书前面列出的那些标准分类里。

收录在这里的，都是在受欢迎程度、历史，或者所引发的体验方面比较突出的呢。
