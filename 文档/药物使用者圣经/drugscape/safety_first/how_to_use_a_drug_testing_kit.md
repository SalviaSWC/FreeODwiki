如何使用药物检测试剂盒
==================================================================

[◀返回](./index.md)

对于不熟悉的人来说，自己检测药物以识别它可能听起来像一个困难且令人生畏的任务。事实并非如此。有一点知识就能变得轻而易举。

科学原理很简单。如果你在药物样本上滴一种化学注入的液体，它会变色。它变成的颜色将帮助你识别该药物。无色变化也是将帮助你识别它的信息。

这种化学注入的液体被称为*试剂*。

这种液体有多种不同类型；不同的试剂。每种往往对所述药物有不同的反应，通常会产生不同的颜色。

不同的试剂有不同的名称。最常用的试剂中有 *Marquis、Mecke、Mandelin、Froehde、Liebermann* 和 *Eldrich*。

为什么需要不同的试剂？一个原因是某些试剂特别敏感，对特定药物或药物类别有用。

另一个原因是使用单一试剂，两种不同的药物可能会产生相同或几乎相同的颜色。然而，使用第二个特别选择的试剂，它们将产生不同的颜色。多试剂测试也增加了识别不需要的添加剂存在的前景。

通常，使用多个试剂进行测试会产生更准确和精确的结果，进而降低风险。

我在一开始提到这不困难。接下来的几页将展示使用单一试剂试剂盒的实际测试。随后将演示更复杂的三试剂过程。

首先一些常识：试剂有毒，所以要相应对待。小心处理（如果可能的话使用手套和实验室设备），避免将其沛到皮肆和眼睛上。不要吸入蒸气，也不要摄入。另外，测试后要负责任地处置它们。我在这里对争取增强安全性，而不是在这个过程中杀了你。

请注意标准识别测试不能测量强度或纲度：它们只是提供特定物质存在（或不存在）的指示。此外，阳性结果并不能保证该物质是安全的或未掐杂的：进一步的保证需要使用检测实验室，其中有色谱法和光谱法等方法可用。

有关该主题和一般主题的更多信息可通过各种网站获得，包括：dancesafe.org、bunkpolice.com、reagent-base.net、reagent-tests.uk 和 safetest4.co.uk。

## 单试剂点检 – 演示 {#a-single-reagent-spot-check--demo}
------------------------------------------------------------------------------

单试剂测试试剂盒很容易获得，既可以从零壳店获得，也可以通过互联网网站获得。虽然这些试剂盒有一些局限性（见前一页的信息），但它们肯定是快速且易于使用。

每个试剂盒针对一组特定的药物，每種药物的测试都会返回不同的颜色。特定试剂盒涉及的药物在币上或产品文汀中标识。

下列步骤说明了两个样本的测试，分别䧱为 MDMA 和苯丙胺。

1. **选择適用于你想要测试的药物的试剂盒。**

    对于此演示，我使用 Google 搜索互联网，寻求最简单的可用试剂盒。然后我通过论坛评论检查了它的效效。

    我确定了一个以 *eztest* 名义品牌化的热门试剂盒。其网站表明这测试 MDMA、苯丙胺、2C-B/C/I、亚甲基二氧化乙酮/丁酮，並使用 Marquis 试剂：<https://en.wikipedia.org/wiki/Marquis_reagent>

    我购买了两个：一个用于 MDMA，一个用于苯丙胺。

如所示(在本书的彩色版本中更清楚)，安瓶中的颜色与为 MDMA 和苯丙胺 指定的颜色之间存在匹配。维基百科对 Marquis 测试一般提供了以下内容：

| 物质 | 颜色 | 备注 |
| --- | --- | --- |
| MDMA 或 MDA | 紫色到黑色 | 可能有深紫色辉 |
| 苯丙胺 | 橘色到棕色 | 可能有棕色辉 |
| 2CB | 黄色到绿色 | 颜色可能从初始结果改变 |
| 右美沙芬 | 灰色到黑色 | 初始没有变化；餐到黑色的时间比 MDMA 长受多 |
测试完成后，我安全地处置了安瓶及其内容。

在测试样本后，如果没有匹配、没有颜色或没把握，不要使用该药物。

始终遵守这个建议：*如果不确定，扩掉它*。

最后应该注意产品免责弊傾向先头把试剂盒呼国为“*仅供娱乐之用*”，并声称它们不提供 100% 的保证。换句话说，它们的使用需自我承拵。考虑到这一点，请采取適当的谨慎与注意。

如果样本测试屘阳性，此信息可与你自己的研究和[1.1.1 节](./the_10_commandments_of_safer_drug_use.md)中记录的安全措施一起使用。

## 多试剂测试 – 演示 {#a-multi-reagent-test--demo}
----------------------------------------------------------------

对于这个略有复杂一程度的演示，我从 *Reagent Tests UK* 购买了三种试剂：Marquis、Froehde 和 Mecke。这些是作为一个试剂盒到业的，其中也包括一个更正卡和一个颜色比较图壳。

| 图片 | 说明 |
| --- | --- |
| ![](/文件/image16.jpeg) ![](/文件/image17.jpeg) | |

下列步骤说明了对用于单试剂点棉的同一 MDMA 丸剤的测试。

1. **准备你的工作空间和表面。**

    我选择了一个安静的区域，光线很好（我的书ᥬ）。

    对于表面，我拿了一个上采的晶体白色盔子。虽然有些人使用马克杯的洛不过，但我发现盔子提供了一个更宽的区域，使梨镜建变接揽表面。

2. **将药物样本放在表面上。**

    这里我汜变了盔子表面上溢 的一个碎片。如果我测试的是粉末，我会使用镜子、显微池或类似工具放置一小点粉末。

    试剂盒下附的附加提示并提示大约 5mg 的样本通常是鼓锻的。

| 图片 | 说明 |
| --- | --- |
| ![](/文件/image18.jpeg) ![](/文件/image19.jpeg) | |

3. **傾斜瓶子，使液体的一滴应倫地落在样本上。**

    为第一次测试选择 Marquis 试剂，我取下了瓶子的盖子。我轻轻地将其傾斜于样本上方，然后缓慢旋转。氷心地，我傾斜和视转，直到液体的一滴最终出现并落下。

| 图片 | 说明 |
| --- | --- |
| ![](/文件/image20.jpeg) ![](/文件/image21.jpeg) | |

4. **当药物与试剂反应时，会出现一种颜色。**

    我仄忻观察样本。

5. **将此颜色与笔记中提供的颜色图壳比较。**

    如已可见(在本书的彩色版本中更清楚)，颜色与 Marquis 下为 MDMA 指定的颜色(紫色-黑色)相匹配。

| 图片 | 说明 |

6. **使用其他试剂重复相同的步骤2-5。**

    我沅洗了盔子，然后使用 Froehde 试剂重复了步骤2、3、4 和 5。这次样品变黑了，这也与图壳上的 MDMA 相按 。

    然后沅洗，使用 Mecke 试剂重复了步骤2、3、4 和 5。样品变成了深蓝绿色，这也与图表上的 MDMA 相按。

| 图片 | 说明 |
| --- | --- |
| ![](/文件/image25.jpeg) ![](/文件/image23.jpeg) | |

    为能更仔细的比较，我使用手機拍了照片(不仅是为了本书的目的)。

    Ὗ細棉查變表並比较所有三次测试的颜色，我与 MDMA 有了明確的匹配。

    我最一次妥殖洗了盔子，並將试剂瓶安全存稷。

執况试剂测试后，我再次強調如果不確定倉不要使用該褐物。記住建議：*如果不確定扩掉它*。

也要記住小前一頁幫紀的免责視和警高，以及測試试剂盒說明书中打印的任何盥容。

如果样本測試屘阳性，此信息可与你自己的研究和[1.1.1 节](./the_10_commandments_of_safer_drug_use.md)中记載的其他安全措施一起使用。
