**4.8.3 多药联用** [\#](#poly-drug-combinations)
================================================

[◀返回](./index.md)

将不同药物组合在一起会显著增加风险，整体上并不推荐呢。即使简单看看名人药物致死案例的死亡证明，也能清楚看到*联合药物中毒*（CDI）的危险性。想了解更多的话，可以参考本书第一部分提到的TripSit药物联用图表哦。

以下是一份不完整的常见联用列表。请注意，这些是大家对这些名称的一般理解，实际成分有时可能会有所不同。

* *Atom Bomb*：大麻 + 海洛因
* *Black Hash*：鸦片 + 哈希
* *Black Russian*：鸦片 + 哈希
* *Buddha*：大麻 + 鸦片
* *Candy Blunt*：大麻 + 右美沙芬
* *Candy Flip*：LSD + MDMA
* *Cherry Meth*：GHB + 甲基苯丙胺
* *CK1*：可卡因 + 氯胺酮
* *Cracid*：可卡因 + LSD
* *Croak*：霹雳可卡因 + 甲基苯丙胺
* *Eightball*：霹雳可卡因 + 海洛因
* *EKG*：MDMA + 氯胺酮 + GHB
* *El Diablo*：大麻 + 可卡因 + 海洛因
* *Elephant Flip*：MDMA + PCP
* *Fire*：可卡因（霹雳）+ 甲基苯丙胺
* *Frisco Special*：可卡因 + 海洛因 + LSD
* *Fry Daddy*：霹雳可卡因 + 大麻
* *Gamma Flip*：MDMA + GHB
* *Gasid*：LSD + 一氧化二氮
* *God’s Flesh*：LSD + 蘑菇
* *H & C*：海洛因 + 可卡因
* *Hippie Flip*：MDMA + 蘑菇
* *Hippie Flip On A String*：MDMA + 蘑菇 + 可卡因
* *Jedi Flip*：蘑菇 + LSD + MDMA
* *Kitty Flip*：MDMA + 氯胺酮
* *Love Flip*：MDMA + 麦斯卡林
* *LSDXM*：LSD + 右美沙芬
* *Missile Base*：可卡因 + PCP
* *Nexus Flip*：2C-B + MDMA
* *Nox*：MDMA + 一氧化二氮
* *Outer Limits*：可卡因（霹雳）+ LSD
* *Poppy Flip*：MDMA + 阿片类药物
* *Shaman Flip*：MDMA + DMT
* *Speedball / Powerball*：可卡因 + 海洛因 或 吗啡
* *Snow Seals*：可卡因 + 苯丙胺
* *Sugar Flip*：MDMA + 可卡因
* *Trailer Flip*：甲基苯丙胺 + MDMA
