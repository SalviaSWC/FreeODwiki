**荷兰连接（阿姆斯特丹）** [\#](#荷兰连接阿姆斯特丹)
======================================================================

其实呢，并没有特别的“荷兰连接”啦，除了荷兰是好几种热门娱乐性药物的主要来源地（比如MDMA）以外哦。不过呢，阿姆斯特丹可是实打实的呢，这里有好多国际游客专程跑来，享受咖啡店和整体上更宽容、更文明的药物态度嘛。所以这本书呢，如果不简单介绍一下这个场景（从外国游客的角度），就会显得不完整哦～

作为顾客呢，主要有三个感兴趣的来源：咖啡店（卖大麻）、种子银行（卖种子）和智能店（卖合法化学品、植物制品和周边用品）。虽然这些店呢，都散布在阿姆斯特丹市中心，但质量和性价比可不是都一样的哦，建议大家提前做做功课再去呢。

为了给大家画一幅比较真实的“实地情况图”嘛，我在2017年呢，特意拜访了几家口碑最好的店铺，并向每家的店员问了一系列问题。下面就是他们的回答啦～

**阿姆斯特丹：一般安全建议** [\#](#阿姆斯特丹一般安全建议)
-----------------------------------------------------------------------

要注意哦，在阿姆斯特丹玩的时候呢，你平常的安全习惯可千万不要松懈呢。不过呢，有些安全措施在这里比其他地方容易实施多了。比如药物检测就很方便哦。

这里有好几家机构呢，只收一点点费用，就可以匿名帮你检测药物。详细信息如下：

|  |  |
| --- | --- |
| GGD Amsterdam<br>Valckenierstraat 4, 1018 XG Amsterdam<br>+3120-5555450<br>[www.ggd.amsterdam.nl](http://www.ggd.amsterdam.nl) | ![](/文件/image583.jpeg) |

|  |  |
| --- | --- |
| Jellinek<br>Jacob Obrechtstraat 92, 1071 KG Amsterdam<br>+3120-5901590<br>[www.jellinek.nl](http://www.jellinek.nl) | ![](/文件/image584.jpeg) |

我去GGD的时候呢，很幸运地遇到了服务相关的人员，聊到了一些背景信息。他们主要服务对象呢，当然是荷兰本地人啦。游客也可以检测，但要记得，除了基本的试剂检测和数据库查询以外，完整的实验室检测有时要花超过一周时间呢。

他们一年中最忙的时候呢，通常是音乐节季节（夏末），我2017年8月去的时候呢，最常送检的药物依次是摇头丸/MDMA、可卡因、氯胺酮和2C-B。每人最多可以送3个样本哦。

从我个人经验来说呢，有一条通用建议：不要玩得太过火。强力品种的大麻很容易抽太多，松露也容易吃过头呢。

如果你计划来一次强烈的旅程呢，最好准备好安全网，比如离酒店近一点，或者找个能安心放松、远离人群的地方。一定要有陪护人哦～

买松露或其他东西的时候呢，和店员好好聊聊你的需求，他们会给你建议，包括剂量什么的。如果你买的是蘑菇（智能店不卖，因为违法），要记得鲜重和干重的区别哦。

最后呢，我一直觉得阿姆斯特丹是个超级友好的城市，就像前面那些采访里体现的那样。如果你想了解更多呢，尽管问当地的爱好者们就好啦～

--------------------------------

对于大麻爱好者来说呢，位于红灯区边缘的《Hash, Marijuana & Hemp Museum》是个不错的选择哦。

沿着同一条运河（Oudezijds Achterburgwal）再往下走呢，就是*Cannabis College*，他们提供娱乐性和药用大麻的安全使用建议，还可以免费参观他们的小型大麻花园（见下图）哦。

| ![](/文件/image589.jpeg) | |
| --- | --- |
| If you intend to trip on truffles or another psychedelic, Amsterdam is blessed with an abundance of world class art galleries and museums, to suit every taste. The term *museum dose* was not coined without good reason. | |

如果你打算用松露或其他迷幻剂来次旅程呢，阿姆斯特丹有超多世界级的艺术画廊和博物馆，可以满足各种口味。“博物馆剂量”这个说法呢，可不是随便起的哦～

另外呢，不管是迷幻剂还是大麻，都有很多开放空间可以放松，尤其是Vondelpark。我个人呢，很喜欢在Rembrandtplein一边嗨一边看人来人往，不过其他好地方也多得是啦。

虽然有合法的选择，但我还是稍微提一下酒精吧：这里有啤酒厂（推荐那个在风车里的*Brouwerij ‘t IJ*），有Icebar，还有好多酒吧和pub（可以试试历史悠久的*In de Olofspoort*，当时有超惊人的烈酒和杜松子酒选择）。喜欢烟草的朋友可以去Rokin的*P.G.C. Hajenius*，那里有海量雪茄，还有专门的吸烟室呢。

对我来说呢，阿姆斯特丹是个既能放松又能探索的绝佳目的地，几乎每个角落都有惊喜。整体氛围呢，又迷人又chill，超级适合有品位又爱冒险的游客哦～

**一段趣闻（阿姆斯特丹）** [\#](#一段趣闻阿姆斯特丹)
----------------------------------------------------------------

有时候呢，在我们这个对药物有点 paranoia 的文化里，事情会变得特别离奇。有一次我在阿姆斯特丹史基浦机场，口袋里装着两根大麻烟。

我的行程呢，是先飞去亚洲研究四天，然后回史基浦转机，要等6个小时再飞下一程。

于是问题来了：这些烟不能带走，那该怎么办呢？

我当时想了个“聪明”主意——把它们埋在机场航站楼外面的一个花盆里，等回来的时候挖出来，在漫长的转机时间里抽掉，开心一点嘛。我在门口附近找到这个小可爱，然后把防水包装好的宝贝埋在土壤右边。
